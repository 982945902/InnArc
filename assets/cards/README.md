# 心镜标准 78 张塔罗卡面

本目录只把 `source/`、`webp/`、`thumbs/` 作为当前生产资源。早期方向错误的“心理投射卡”保存在 `drafts/reflection-deck/`，不会被产品或资源清单引用。

## 生产规格

- 体系：标准 Rider–Waite–Smith 78 张分类与经典图像语义。
- 风格：原创穆夏式新艺术插画；完整金色植物纹边框；顶部圆形章与底部标题框留空，由界面叠加准确名称。
- 原图：1024×1536 PNG。
- 线上图：800×1200 WebP，质量 72。
- 缩略图：240×360 WebP，质量 62。
- 牌背：`card-back`，与卡面使用同一比例。

每张图以对应生产卡面为风格参考单独生成。共用提示词要求：原创、标准经典构图、指定物件数量、无内嵌文字/数字/标志/水印、完整四边框、空白标题框。每张牌的具体构图要求保存在 `packages/deck/src/deck-data.json` 的 `artBrief` 字段中。

运行 `pnpm assets:manifest` 会校验三套图片尺寸并生成带 SHA-256 的 `assets/card-manifest.json`。发布门禁会再次核对标准名称、ID、图片路径和资源摘要，防止卡名与落卡画面再次错位。
