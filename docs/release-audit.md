## 自动验证

```bash
pnpm assets:manifest
pnpm preflight
pnpm check
pnpm test
pnpm build
```

当前本机证据：

- `pnpm preflight`：0 失败，0 警告。
- `pnpm check`：前后端与共享包通过。
- `pnpm test`：牌库、任务租约与“问题 → 追问 → 78 选 3 → `202 taskId` → 完整解读”接口测试通过。
- Taro 微信小程序构建：成功，产物约 500 KB，不内嵌 13 MB 卡面，卡面走 CDN。
